# Task Manager React

A simple and responsive Task Manager application built with React and Vite.

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Search tasks
- Filter tasks by All, Pending and Completed
- Clear all completed tasks
- Task statistics
- Data persistence using Local Storage
- Responsive design for mobile and desktop

## Technologies Used

- React
- JavaScript
- Vite
- HTML
- CSS
- Local Storage
