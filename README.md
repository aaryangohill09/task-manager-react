# Task Manager React

A responsive Task Manager application built with React and Vite.

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Search tasks
- Filter tasks by All, Pending and Completed
- Clear completed tasks
- Task statistics
- Local Storage persistence
- Responsive design

## Technologies Used

- React
- JavaScript
- Vite
- HTML
- CSS
- Git
- GitHub
- Local Storage
